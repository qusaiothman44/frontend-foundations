#so we have a main concept in the web:

##1: Browser which is a software that present the user interface but it understand HTML ,CSS and JS , so when we type "www.google.com" the DNS (domain name system) to resolve the human language to IP the IP is a logical address where we can find the website.

##2: server which is a software that handle the logic and resaves HTTTP  requests 

##3: HTTP requests it's a protocol between the browser and the server 

##4:status Codes it's the results for out request:
200: our request is OK or success 
301: the request moved to another location
404: the page is not found
500: something wrong in the server side
